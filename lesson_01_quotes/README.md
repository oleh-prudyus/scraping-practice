# Урок 1 — Перший скрапер (quotes.toscrape.com)

Навчальний сайт [quotes.toscrape.com](http://quotes.toscrape.com) спеціально зроблений для практики скрапінгу — статичний HTML, без захисту від ботів.

## Завдання

1. Відкрити сторінку `http://quotes.toscrape.com` через Playwright
2. Знайти всі цитати на сторінці (кожна — блок з класом `.quote`)
3. Для кожної цитати вивести в консоль:
   - текст цитати (`.text`)
   - автора (`.author`)
4. Порахувати і вивести загальну кількість знайдених цитат

## Підказки

- Використай `playwright codegen http://quotes.toscrape.com`, щоб подивитись, як браузер сам знаходить елементи при кліку — це допоможе зрозуміти селектори
- `page.locator(".quote")` поверне всі елементи одразу — це список локаторів
- Щоб перебрати всі знайдені елементи, глянь на `.all()` в документації Locators: https://playwright.dev/python/docs/locators
- Не забудь `browser.close()` в кінці

## Критерій виконання

Скрипт запускається командою:
```bash
python lesson_01_quotes/scraper.py
```
і виводить у консоль ~10 цитат (перша сторінка сайту) з авторами та підсумкову кількість.

## Наступний крок (опційно, якщо перше вийшло легко)

Сайт має кілька сторінок (пагінація, кнопка "Next"). Спробуй зібрати цитати з усіх сторінок, а не тільки з першої.
